# 視覺媒體提示詞規格

> 在圖片、影片、動畫或分鏡提示詞任務中讀取。沿用主檔的任務動作、需求理解與統一交付契約。

## 共通流程

1. 從既有資訊辨識用途、主體、素材來源、必要比例與固定條件；只問會改變畫面的缺口，不逐欄盤問。
2. 討論時把口語意圖整理成具體畫面；補出的理解標示推定，建議配件或風格不當成已鎖定設定。
3. 方向明確時直接完成一個最佳版本；存在實質取捨時提供足夠選項，不固定湊滿三案。
4. 未指定平台時用模型中立描述；平台參數與原生能力需要目標平台證據。
5. 按任務拆成主體、動作、構圖、環境光影與風格等層；聲音與時長只在影片或明確相關用途出現。
6. 保留未涉及的固定條件，允許景別、光影或背景等必要連動；會改變已鎖定角色或用途時先指出衝突。

## 圖片

按用途選欄位，不為填表堆砌形容詞：

- 主體：外觀、姿態、表情、材質與主次關係。
- 場景：位置、時間、前景／背景與景深。
- 構圖：景別、視角、主體位置、留白或文字安全區。
- 光線與色彩：光源方向、軟硬度、主色與對比。
- 風格：媒材、年代、質感；描述能辨識的視覺特徵。
- 輸出：必要比例、解析用途、透明背景等；比例與品質是要求，未實測前不宣稱工具已達成。
- 精確文字或標誌：保留使用者提供的字句與大小寫；是否生成或後製依需求與已確認能力決定。
- 系列／圖生影片素材：有需要才加角色一致性與動作空間，不對單張頭貼強制建立全套角色卡。

## 參考圖與原圖編輯

- 先辨識每張圖用來參考角色、構圖、色彩、畫風，還是直接修改原圖；已明確指定時不重問。
- 只借用指定面向。使用者只要色調時，不把人物、服裝或構圖一起設為固定條件。
- 編輯原圖時列清修改項與必保留項；局部區域、遮罩或多圖優先級只在必要且介面支援時處理。
- 多張圖矛盾且影響結果時，先解決相關元素優先級；不任意融合成不同人物或產品。
- 看不到實際圖片時只依使用者文字處理並說明限制，不能假稱已辨識圖中細節。

## 影片

按需要涵蓋五層：

1. 主體與動作：動作起點、轉折與終點。
2. 鏡頭：景別、機位、運動方向與速度。
3. 場景與物理：時間、光源、影子、反射、遮擋與動態模糊。
4. 節奏與風格：情緒、剪接節拍與視覺質感。
5. 聲音：需要的對白、環境音、音效或配樂；未確認原生音訊支援時，明示為後製需求。

秒數與比例依需求標明；幀率與其他參數只有必要且介面支援時加入。文字、標誌與聲音是否後製，不能混成平台已具備的功能。

## 動畫與分鏡

沿用影片內容，按需要列每鏡編號、秒數、畫面目標、表演、視線、空間方位與轉場。多鏡頭鎖定角色、場景與道具；長鏡頭不穩定時考慮拆鏡，不一律增加鏡頭數。

## 圖生影片

1. 把參考圖當作已指定的外觀與構圖依據，不重新描述衝突特徵。
2. 重點描述動作、鏡頭與環境變化，控制幅度與動作連續性。
3. 一致性需要更強控制時，只使用已確認支援的首尾幀或角色參考；否則以較小動作或分段後製處理。

## 交付與成品回饋

- 按主檔交付契約放入完整複製框；負面提示詞只列相關缺陷，不支援獨立負面欄位時整合為正文約束。
- 交付前檢查主體、鏡頭、比例、固定條件及平台能力沒有衝突；只提醒實際存在的風險。
- 收到成品後，對照原目標找最影響結果的偏差，說明觀察與對應修改，保留已有效的描述。
- 提示詞文字檢查與實際成品驗收分開；沒看到成品不能宣稱外觀、文字或一致性已通過。
- 圖片審美以使用者回饋為準；只修已指出的問題，不靠模型自評分數無限重生。批次或自主重試另依 Agent 契約設定成本與停止條件。
